Ecuaciones y alcance

Re = VD/ν o VDₕ/ν, con Dₕ = 4A/℘, V = Q/A y ν = μ/ρ.

Laminar si Re < 2300. Se aplica f = 64/Re, que corresponde a flujo plenamente desarrollado en tubería circular. Para otras secciones se muestra como referencia circular.

Transición si 2300 ≤ Re < 4000. El gráfico marca Re mediante una línea vertical. Turbulento si Re ≥ 4000.

En régimen turbulento se resuelve 1/√f = −2 log₁₀(r/3,7 + 2,51/(Re√f)) por bisección, con r = ε/D o ε/Dₕ. Se admite 0 ≤ r ≤ 0,05. El uso de Dₕ en Colebrook–White es aproximado.

El factor de Fanning equivale a f/4.
